# 붐붐솔솔 공식 사이트

GitHub Pages와 Jekyll을 사용하는 정적 사이트입니다. 소스 수정과 공개 게시를 구분합니다. **2026-11-22 웹사이트 개편의 커밋·push·게시를 승인받았습니다. 앱 정식 출시는 계속 보류합니다.**

## 앱 정보 관리

- `_data/apps.yml`: 이름, 아이콘, 소개 주소, 출시 상태, 플랫폼과 공개 스토어 주소를 관리합니다.
- `index.html`, `apps/index.html`, `download/index.html` 및 기존 앱 상세·다운로드는 이 목록을 사용합니다.
- 미출시 앱에는 스토어 주소를 넣지 않습니다. 내부 테스트 초대·심사용 코드는 사이트에 게시하지 않습니다.
- 수학은 `/apps/math/`, 영어는 `/apps/english/`에서 소개합니다. 영어는 확정된 이름·아이콘·출시 예정 안내를 제공합니다.
- 기존 `_config.yml`의 국어·상식 스토어 키는 호환을 위해 보존합니다. 현재 템플릿의 스토어 연결은 앱 목록을 기준으로 합니다.

## 로컬 빌드와 검증

기존 Gemfile·Gemfile.lock의 Jekyll 환경을 사용합니다. 앱 SDK나 런타임 프레임워크를 추가하지 않습니다. Node 도구는 CSS를 미리 생성하는 데만 사용하며, GitHub Pages는 커밋된 `assets/css/site.css`를 그대로 제공합니다.

```sh
npm ci
npm run build:css
bundle exec jekyll build
npm run check
```

CSS 빌드 도구는 `tailwindcss@3.4.17`로 고정합니다. HTML의 유틸리티 클래스를 바꾸면 CSS도 다시 생성해야 합니다. 배포 사이트에서 Tailwind·폰트·아이콘 CDN을 실행하지 않습니다. 아이콘은 정적인 SVG이며 서체는 기기의 시스템 서체를 사용합니다.

`scripts/check_site.py`는 빌드 결과의 내부 링크·앵커·이미지·스타일, H1·메타데이터·JSON-LD·사이트맵, 미출시 앱의 잘못된 설치 버튼을 검사합니다. 결제·구독·메일 발송은 하지 않습니다.

## 정책과 이전 주소

- 개인정보처리방침 `/privacy/`, 이용약관 `/terms/`는 공통 조항과 앱별 섹션으로 구성합니다.
- 수학 상세 문서는 `_includes/legal/`에 있으며 앱 문서와 동작이 바뀌면 함께 확인합니다.
- `/account-deletion/`는 실제 공식 이메일을 통한 삭제 요청 방법을 안내합니다. 자동 삭제 기능을 새로 만든 것이 아닙니다.
- 이전 공개 문서는 `/policies/2026-06-26/privacy/`, `/policies/2026-06-26/terms/`에 보존하며 검색 대상에서 제외합니다.
- 이번 개정은 2026-11-22에 공개하는 공식 연락처·앱별 처리 현황·이용 안내의 정리입니다. 기존 계약·구매 권리와 기존 구매 계약의 제공 조건을 변경하지 않습니다. 기존 계약 조건 변경은 적용일·사전 안내·필요한 동의를 별도로 진행하며 과거 효력을 소급 변경하지 않습니다.
- 기존 `/download/vocabulary/`, `/apps/vocabulary/`, `/apps/facts/`와 `/words/<글주소>/`를 보존합니다. `/words/` 목록은 `/breeze/`를 대표 주소로 안내합니다.

## 게시·운영 확인

1. 앱별 실제 운영 버전과 정책을 마지막 대조합니다. 2026-11-22 Supabase 프로젝트 목록을 읽어 국어(ap-northeast-2, 서울)·상식(ap-southeast-2, 시드니)의 실제 리전을 확인하고 종전 미국 표기를 정정했습니다. 수학 핵심 DB의 서울 안내는 기존 확인 자료를 유지합니다. 제공업체별 국외 이전 고지·보관 기간과 필요한 법적 절차도 확인합니다. 문구 수정이 동의·보호자 확인 기능이나 법적 요건의 이행을 대신하지 않습니다.
2. 기존 계약 조건을 변경할 때에는 적용일·주요 변경 공지와 필요한 사전 절차를 확인합니다. 이번 작업의 이메일 검수는 링크·표기 확인이며 실제 수신 테스트는 하지 않았습니다. 운영 중 공식 이메일 수신도 확인합니다. 영어의 실제 기능·처리 정보가 확정되면 출시 전에 개별 안내를 보완합니다.
3. 320·375px부터 태블릿·가로 화면·데스크톱과 글자 200%, 키보드 메뉴·FAQ·문서 표·다운로드 연결을 확인합니다.
4. 승인된 사이트 변경만 커밋·push합니다. 자동 GitHub Pages 게시와 앱 마켓 출시는 별개입니다. 앱 출시는 별도 승인 없이 진행하지 않습니다.

`CNAME`과 `app-ads.txt`의 기존 게시자 두 줄은 유지합니다. 도메인·스토어 앱 식별자·앱 계정·DB·결제 설정은 이 개편으로 변경하지 않습니다.

이미지 원본 PNG는 보존하고 실제 페이지는 경량 WebP를 참조합니다. `_site/`는 생성 결과이므로 직접 수정하지 않습니다.
