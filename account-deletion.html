개인정보 권리 행사

계정·데이터 삭제 안내

국어:어휘의 신 · 수학:연산의 신 · 국어:상식의 신

1. 삭제 요청 방법

앱에 계정 삭제 기능이 제공되는 경우 해당 메뉴에서 요청할 수 있습니다. 앱을 사용할 수 없거나 이메일 접수를 원하면 다음 주소로 요청해 주세요.

{{ site.company.email }}

  1. 제목에 “앱 이름 / 계정·개인정보 삭제 요청”을 적어주세요.
  2. 앱 이름과 삭제할 범위(계정 전체 또는 특정 정보), 계정 연결에 사용한 이메일 등 확인에 필요한 최소 정보를 적어주세요.
  3. 게스트는 연결한 이메일이 없다는 점과 앱에 표시된 별명·학습자 또는 기기 식별 정보를 알려주세요. 비밀번호·인증 토큰은 보내지 마세요.

회사에서 본인 또는 적법한 대리인 확인에 필요한 사항과 처리 범위를 안내하고, 확인 후 관계 법령의 기한 내에 결과를 알려드립니다. 법정대리인도 아동의 권리 행사를 요청할 수 있습니다.

2. 삭제되는 정보

확인된 계정과 관련된 프로필, 서버 학습 저장본, 알림 등록 등 요청 범위의 개인정보를 삭제 대상으로 처리합니다. 계정과 연결되지 않은 의견·문의는 접수 ID 등 별도의 확인 정보가 필요할 수 있습니다.

서버 삭제가 다른 기기의 오프라인 기록이나 운영체제 백업을 동시에 제거하지는 않습니다. 기기 내 기록과 백업은 해당 기기·서비스에서 함께 관리해 주세요. 로그아웃과 앱 삭제만으로 서버 계정이 삭제되는 것은 아닙니다.

3. 별도로 보관할 수 있는 정보

법령상 보존 의무가 있는 계약·결제·청약철회 기록은 5년, 소비자 불만·분쟁 기록은 3년 등 해당 기간 동안 필요한 항목만 별도로 보관합니다. 구매 권리 확인·부정 재귀속 방지 등으로 남겨야 하는 최소 자료와 제한 사유가 있으면 요청 처리 시 안내합니다. 전체 학습 기록을 일괄적으로 보존한다는 뜻은 아닙니다.

4. 구매와 구독도 확인해 주세요

계정 삭제는 자동 갱신 구독 취소나 환불 신청과 다릅니다. 구독은 구매한 스토어에서 별도로 취소해 주세요. 일회성 구매는 자동 갱신되지 않습니다. 삭제한 학습 기록은 구매 복원으로 되살릴 수 없습니다.
